# 📱 Lingua — английский каждый день

Мобильное приложение (PWA) для изучения английского. Устанавливается на телефон иконкой, открывается на весь экран и работает без интернета. Сервер и сборка не нужны.

## Что внутри

- **584 слова**, из них **518 уровня B1–C1**:

  | Набор | Слов | Что за слова |
  |---|---|---|
  | 🌿 B1 · Intermediate | 208 | быт, работа, путешествия, эмоции |
  | 🚀 B2 · Upper-Intermediate | 205 | учёба, работа, дискуссии, новости, фразовые глаголы |
  | 🎓 C1 · Advanced | 105 | точные формулировки для статей, переговоров, отчётов |
  | 🌱 A1–A2 · Базовый | 35 | дополнительный набор для разминки |
  | 💻 IT / Tech English | 31 | лексика разработчиков |

  У каждого слова есть транскрипция, перевод и пример. Само слово в примере стоит в той же форме, поэтому все слова участвуют в упражнениях.

- **Карточки с интервальным повторением.** Тап по карточке переворачивает её. **Свайп вправо** — «Знаю», **свайп влево** — «Забыл». Есть кнопки и вибрация при ответе.
- **Тренажёры:** «Пропущенное слово», «Найди пару» и «Конструктор предложений».
- **Грамматика:** 4 темы со шпаргалками и тестами.
- **Главная:** стрик, дневная цель, статистика, график за неделю.
- **Словарь:** поиск по всем словам, добавление своих слов, настройки, экспорт и импорт прогресса.
- **Внешний вид:** светлая и тёмная тема, нижняя панель вкладок, поддержка «чёлки» iPhone.

## Как установить на телефон

Чтобы приложение установилось на телефон и работало офлайн, папку нужно разместить на любом **https**-хостинге. Это бесплатно и занимает пару минут.

### Вариант 1. Netlify Drop (проще всего, без регистрации)

1. На компьютере откройте **https://app.netlify.com/drop**.
2. Перетащите туда папку `english-app` целиком.
3. Netlify даст ссылку вида `https://что-то.netlify.app`. Откройте её на телефоне.
4. Установите приложение:
   - **Android (Chrome):** на главной появится карточка «Установите Lingua», нажмите **«Установить»**. Ещё можно выбрать в меню **⋮ → «Установить приложение»**.
   - **iPhone (Safari):** нажмите **«Поделиться» ⬆︎ → «На экран „Домой“»**.

Без регистрации ссылка на Netlify Drop живёт около часа. Чтобы она работала постоянно, создайте бесплатный аккаунт и нажмите «Claim site».

### Вариант 2. GitHub Pages (постоянная ссылка)

1. Создайте репозиторий на GitHub и загрузите в него содержимое папки `english-app`.
2. Откройте **Settings → Pages → Branch: main → Save**.
3. Через минуту приложение будет доступно по адресу `https://ваш-логин.github.io/имя-репозитория/`. Установите его так же, как в варианте 1.

### Вариант 3. С компьютера по Wi-Fi (быстрая проверка)

```bash
cd english-app
python3 -m http.server 8000
```

На телефоне в той же сети откройте `http://IP-компьютера:8000`. Приложение будет работать, но офлайн-режим и установка не включатся: браузеры разрешают их только на https.

### Вариант 4. На компьютере

Дважды кликните по `index.html`. Всё работает, кроме офлайн-режима.

## Можно ли сделать APK для Google Play?

Можно. Разместите приложение на https (вариант 1 или 2), затем откройте **https://www.pwabuilder.com**, вставьте ссылку и нажмите **Package for stores → Android**. Получится готовый APK/AAB, который можно поставить на телефон или загрузить в Google Play. Код менять не нужно.

## Офлайн-режим

Файл `sw.js` (service worker) сохраняет приложение на телефоне при первом открытии, включая стили и шрифты. Дальше всё работает без сети.

**Обновили файлы?** Увеличьте номер `VERSION` в `sw.js` (например, `lingua-v3`). Телефоны скачают новую версию при следующем открытии.

## Жесты и горячие клавиши

| Действие | Телефон | Компьютер |
|---|---|---|
| Перевернуть карточку | тап | `Пробел` / `Enter` |
| Знаю | свайп → | `2` |
| Забыл | свайп ← | `1` |
| Проверить ответ в «Пропущенном слове» | кнопка | `Enter` |

## Как работает интервальное повторение

У каждого слова есть «коробка» от 0 до 6. Ответ «Знаю» переносит слово в следующую коробку, ответ «Забыл» возвращает его в коробку 0. Через сколько слово покажется снова:

| Коробка | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| Следующий показ | в этой же сессии | 1 день | 3 дня | 7 дней | 16 дней | 35 дней | 75 дней |

За одну сессию приложение показывает все слова, которые пора повторить, плюс 10 новых. Количество новых меняется в «Словаре».

Слово считается **«выученным»**, когда на него хотя бы раз ответили «Знаю». В **«долгой памяти»** — когда интервал повторения достиг 7 дней.

## Структура файлов

```
english-app/
├── index.html            — каркас, подключение PWA, Tailwind, шрифтов
├── manifest.webmanifest  — название, иконки, цвета для установки на телефон
├── sw.js                 — офлайн-режим (кэширование)
├── icons/                — иконки приложения (192, 512, maskable, iOS)
├── styles.css            — анимации, свайпы, шторки, safe-area
├── data.js               — наборы A1–A2 и IT + грамматика
├── words-b1.js           — 208 слов B1
├── words-b2.js           — 205 слов B2
├── words-c1.js           — 105 слов C1
├── app.js                — вся логика
└── README.md
```

Технологии: HTML, Tailwind CSS (CDN), чистый JavaScript без сборщиков, данные хранятся в `localStorage`.

## Как добавить слова

**Через приложение:** откройте «Словарь» → «Добавить слово».

**В код:** добавьте строку в нужный файл `words-*.js`:

```js
["serendipity", "/ˌserənˈdɪpəti/", "счастливая случайность", "Meeting her was pure serendipity."],
```

Пример должен содержать само слово в той же форме, иначе оно не попадёт в упражнение «Пропущенное слово». После правки увеличьте `VERSION` в `sw.js`.

## Прогресс

Прогресс хранится на устройстве (ключ `lingua.v1`). Если вы пользовались первой версией приложения, прогресс по набору «B1–B2» автоматически перенесётся в новый набор B2.

Чтобы перенести прогресс на другое устройство, используйте **Словарь → Настройки и данные → Экспорт / Импорт**.
